=====================================================
 GUÍA DE COMANDOS - CUSTOM QUICKSHELL
=====================================================

1. LANZADOR Y BUSCADOR DE APLICACIONES (App Launcher)
-----------------------------------------------------
• Abrir/Cerrar el Buscador y Lanzador de Aplicaciones:
    shell-apps
    Atajo Hyprland: SUPER + Espacio

• Atajos dentro de la ventana de Aplicaciones:
    Escribir texto : Filtra aplicaciones al instante con animaciones fluidas
    ↑ / ↓ : Navegar entre los resultados
    Enter : Lanzar la aplicación seleccionada
    Esc : Cerrar ventana


2. GESTIÓN DE TEMAS (Dark / Light / Personalizados)
-----------------------------------------------------
• Abrir/Cerrar el Selector de Temas Minimalista (UI):
    shell-theme
    Atajo Hyprland: SUPER + SHIFT + T

• Listar todos los temas instalados en JSON/CLI:
    shell-theme list

• Cambiar tema directamente desde terminal/atajo:
    shell-theme set tokyo-night
    shell-theme set gruvbox-dark
    shell-theme set catppuccin-latte

• Instalar un tema nuevo (desde archivo JSON, carpeta, .zip o URL/Git):
    shell-theme install ~/Descargas/mi-tema.json
    shell-theme install ~/Descargas/tema-cyberpunk.zip --apply
    shell-theme install https://ejemplo.com/temas/nordic.tar.gz --apply

• Crear una plantilla para un nuevo tema en ~/.config/quickshell/themes/:
    shell-theme create neon-sunset --name "Neon Sunset"
    shell-theme create paper-white --name "Paper White" --light

• Exportar o empaquetar un tema para compartirlo:
    shell-theme export neon-sunset ~/Descargas/neon-sunset.zip

• Eliminar un tema personalizado:
    shell-theme remove neon-sunset

• Ver guía completa de creación de temas:
    cat GUIA_TEMAS.md

• Atajos dentro de la ventana de Temas:
    ↑ / ↓ / ← / → : Navegar entre temas
    Enter / Espacio : Aplicar tema enfocado
    Esc : Cerrar ventana


3. GESTIÓN DE FONDOS DE PANTALLA (WALLPAPERS)
-----------------------------------------------------
• Abrir/Cerrar el Selector de Fondos de Pantalla (UI):
    shell-wallpaper
    Atajo Hyprland: SUPER + SHIFT + W

• Abrir la carpeta de wallpapers en el explorador de archivos:
    shell-wallpaper folder
    (o dentro de la ventana de wallpapers presionar la tecla 'i')

• Carpeta de Wallpapers:
    ~/Pictures/Wallpapers

• Atajos dentro de la ventana de Wallpapers:
    ↑ / ↓ : Navegar entre imágenes disponibles
    Enter / Espacio : Aplicar fondo enfocado
    i : Abrir la carpeta ~/Pictures/Wallpapers en el explorador de archivos (Nautilus) para añadir nuevas imágenes
    Esc : Cerrar ventana


4. GUÍA DE ATAJOS Y COMANDOS DEL SISTEMA (Keybinds Cheatsheet)
-----------------------------------------------------

    shell-keybinds
    Atajo Hyprland: SUPER + K


5. CONFIGURACIÓN DE PANTALLAS Y MONITORES (Multi-Monitor Manager)
-----------------------------------------------------
• Abrir/Cerrar la Ventana de Control de Monitores:
    shell-monitors
    Atajo Hyprland: SUPER + SHIFT + S

• Funciones disponibles:
    - Perfiles rápidos: Extender, Solo Externo (apaga laptop), Solo Laptop, Duplicar (Espejo).
    - Selector táctil de escala HiDPI (100%, 125%, 150%, 175%, 200%).
    - Selección visual de resolución y tasa de refresco (Hz).
    - Rotación y orientación de pantalla (Normal, 90°, 180°, 270°).
    - Encendido y apagado individual de salidas.

• Características de la Guía:
    - Buscador interactivo en tiempo real por acción, tecla o descripción.
    - Filtros por categoría: Todos, Lanzadores y Shell, Ventanas, Espacios de Trabajo, Portapapeles, Sistema y Comandos CLI.
    - Renderizado de teclas tipo Key-caps físicos elegantes.
    - Esc : Cerrar ventana

• SUPER + SHIFT + W         : Selector de Wallpapers
• SUPER + SHIFT + T         : Selector de Temas
• SUPER + SHIFT + C         : Activar/Desactivar Modo Cafeína (evita suspensión y bloqueo)
• SUPER + SHIFT + R         : Grabación de Pantalla (área completa o región, audio y micrófono)
• SUPER + SHIFT + P         : Cuentagotas de Color (inspección interactiva HEX, RGB, HSL, HSV)
• SUPER + Espacio           : Lanzador de aplicaciones
• SUPER + N                 : Panel / Centro de Notificaciones y Mensajes
• SUPER + ESC (o SUPER + M) : Menú de Apagado y Sesión (Apagar, Reiniciar, Suspender, Bloquear, Cerrar Sesión, Hibernar)
• SUPER + E                 : Explorador de archivos (Nautilus)
• SUPER + Flechas           : Cambiar foco entre ventanas
• SUPER + SHIFT + Flechas   : Mover ventanas de posición en la pantalla


7. SISTEMA DE NOTIFICACIONES Y CENTRO DE MENSAJES
-----------------------------------------------------
• Abrir/Cerrar el Panel Lateral de Notificaciones:
    shell-notifications
    Atajo Hyprland: SUPER + N

• Control por comandos CLI:
    shell-notifications toggle       # Alternar apertura/cierre del panel lateral
    shell-notifications dnd          # Alternar modo Silenciar / No Molestar (DND)
    shell-notifications clear        # Limpiar todo el historial de notificaciones
    shell-notifications pos left     # Mover panel lateral a la izquierda
    shell-notifications pos right    # Mover panel lateral a la derecha

• Características integradas:
    - Notificaciones emergentes (Toasts) flotantes en la esquina configurada.
    - Reproducción de sonido de alerta personalizado nativo (notification.mp3).
    - Botón "󰆏 Copiar" para copiar rápidamente textos de mensajes o chats recibidos.
    - Botón "󰌑 Abrir" o clic sobre la tarjeta para abrir la app o acción asociada.
    - Barra de progreso de auto-cierre con pausa interactiva al pasar el cursor (hover).
    - Panel lateral deslizable (Drawer) configurable a la izquierda o derecha con persistencia.
    - Selector directo en cabecera del panel para alternar entre lateral Izquierdo y Derecho.
    - Interruptor "󰂛 Silenciar" (No Molestar) que detiene sonido y popups visuales.
    - Historial con opción de eliminar notificaciones individuales o limpiar todas.
    - Cierre rápido mediante tecla Escape o clic en el fondo translúcido.

9. POSICIÓN DINÁMICA DE LA BARRA (Mover a cualquier lateral)
-----------------------------------------------------
• Mover con el ratón (Arrastrar):
    Haz clic sostenido con el botón izquierdo en cualquier espacio vacío de la barra
    y arrastra el cursor hacia el borde de pantalla deseado (Arriba, Abajo, Izquierda, Derecha).
    Aparecerá una guía visual translúcida y un indicador central de acoplamiento.
    Al soltar el botón del ratón, la barra se fijará al lateral elegido automáticamente.

• Comportamiento en Laterales Verticales (Izquierda / Derecha):
    - Se oculta todo el texto (porcentajes, nombres de red, etiquetas de apps).
    - Se muestran exclusivamente los ICONOS limpios centrados.
    - Los escritorios (workspaces) se ordenan verticalmente como puntos/cápsulas.
    - El reloj cambia a un elegante icono "󰥔".
    - Los popouts se despliegan automáticamente alineados al lateral de la barra.

• Cambiar posición por comando CLI:
    shell-bar pos top         # Arriba (horizontal completa con texto)
    shell-bar pos bottom      # Abajo (horizontal completa con texto)
    shell-bar pos left        # Izquierda (vertical minimalista, solo iconos)
    shell-bar pos right       # Derecha (vertical minimalista, solo iconos)
    shell-bar get-pos         # Ver la posición activa actual

11. VISORES MINIMALISTAS PROPIOS (Adaptados a Temas)
-----------------------------------------------------
• Visor de Imágenes Minimalista:
    shell-image [ruta_imagen]
    - Controles flotantes auto-ocultables (fade automático tras 2.5s de inactividad, sin barra de título ni botón de cerrar).
    - Atajos:
        ← / → (o 'h' / 'l') : Imagen anterior / siguiente en la carpeta
        + / - (o Scroll)    : Zoom in / Zoom out
        0                   : Ajustar a ventana / Zoom 100%
        r / R               : Rotar 90° horario / antihorario
        F11 / f             : Pantalla completa
        q / Esc             : Salir

• Reproductor de Video Minimalista:
    shell-video [ruta_video]
    - Solo lienzo de video y controles flotantes translúcidos auto-ocultables (sin barra de título ni botón de cerrar).
    - Atajos:
        Espacio / Clic     : Reproducir / Pausar
        ← / →              : Retroceder / Adelantar 10s (o 5s con 'j' / 'l')
        ↑ / ↓              : Subir / Bajar volumen
        m                  : Silenciar / Activar audio
        l                  : Repetición en bucle (Loop)
        F11 / f / Doble cl.: Pantalla completa
        q / Esc            : Salir

• Visor de Documentos PDF Minimalista:
    shell-pdf [ruta_pdf]
    - Desplazamiento continuo vertical o cambio de página, sin bordes ni botones superfluos.
    - Atajos:
        Scroll             : Desplazamiento continuo vertical
        → / AvPág / Espacio: Página siguiente
        ← / RePág          : Página anterior
        Inicio / Fin       : Primera / Última página
        + / - (o Ctrl+Scr.): Zoom in / Zoom out
        0                  : Alternar Ajustar Ancho / 100%
        i / d              : Alternar Modo Oscuro (invierte colores del PDF)
        F11 / f            : Pantalla completa
        q / Esc            : Salir

* Los tres visores se adaptan dinámicamente en tiempo real al tema activo en el shell.


12. CAPTURA DE PANTALLA MINIMALISTA (shell-screenshot)
-----------------------------------------------------
• Atajos de Teclado Hyprland:
    Print               : Abrir selector flotante de captura
    Shift + Print       : Captura inmediata de área seleccionada
    Super + Print       : Captura inmediata de área seleccionada

• Interfaz Flotante (al presionar Print):
    󰹑  Completa (tecla 1) : Captura toda la pantalla
    󰩭  Área (tecla 2)     : Seleccionar rectángulo con el ratón (slurp)
    Esc / q / Clic fuera: Cancelar selector
    * Presionar Print nuevamente cierra el selector (comportamiento toggle).

• Destino automático:
    - Se guarda automáticamente en formato PNG con fecha y hora en:
      ~/Imágenes/Screenshots/ (o ~/Pictures/Screenshots/)
    - Se copia automáticamente al portapapeles (wl-copy)
    - Muestra notificación flotante con previsualización en miniatura

• Uso por línea de comandos:
    shell-screenshot            # Abre el menú selector interactivo (o lo cierra si está activo)
    shell-screenshot full       # Captura pantalla completa directa
    shell-screenshot area       # Captura área con ratón directa


13. MENÚ DE ENERGÍA Y SESIÓN (shell-power)
-----------------------------------------------------
• Abrir/Cerrar el Menú de Energía:
    shell-power
    Atajo Hyprland: SUPER + ESC (o SUPER + M)

• Opciones y accesos directos:
    1 / P : Apagar el sistema por completo (con confirmación de seguridad)
    2 / R : Reiniciar el equipo (con confirmación de seguridad)
    3 / S : Suspender el equipo a memoria RAM (inmediato)
    4 / L : Bloquear pantalla activa con Hyprlock (inmediato)
    5 / E : Cerrar sesión de Hyprland (con confirmación de seguridad)
    6 / H : Hibernar el sistema en disco (con confirmación de seguridad)

• Atajos dentro de la ventana:
    ← / → / Tab     : Navegar entre tarjetas de acción
    Enter / Espacio : Seleccionar / Confirmar acción
    1 - 6           : Disparador rápido de la acción
    Esc / Clic fuera: Cancelar confirmación o cerrar la ventana

15. INSTALACIÓN Y COMPILACIÓN DE ISO (MRDEMONC-SHELL)
-----------------------------------------------------
• Compilar imagen ISO booteable oficial con mkarchiso:
    ./build-iso.sh

• Grabar ISO generada en pendrive USB:
    sudo dd bs=4M if=out/mrdemonc-shell-*.iso of=/dev/sdX status=progress oflag=sync

• Ejecutar instalador directamente desde ISO oficial de Arch Linux:
    curl -fsSL https://raw.githubusercontent.com/MrDemonc/MrDemonc-SHELL/main/arch-iso-install.sh | bash

• Características del instalador:
    - Asistente de conexión Wi-Fi (redes visibles y redes ocultas con WPA2/WPA3).
    - Selección de Idioma (Español / Inglés) y Teclado (Latam, ES, US).
    - Configuración de Hostname y Git (usuario y correo).
    - Particionado con Btrfs (@, @home, @snapshots, @var_log, @pkg).
    - Cifrado automático completo con LUKS2 (Argon2id).
    - Contraseña Maestra Unificada (LUKS + Root + Usuario).
    - Seamless Login directo a Hyprland en tty1 (sin GDM).


16. HERRAMIENTA DE GRABACIÓN DE PANTALLA (SCREEN RECORDER)
-----------------------------------------------------
• Abrir panel de opciones o detener grabación activa:
    shell-recorder
    Atajo Hyprland: SUPER + SHIFT + R

• Comandos directos por CLI:
    shell-recorder toggle            # Alterna menú o detiene grabación
    shell-recorder stop              # Detiene inmediatamente la grabación
    shell-recorder status            # Devuelve RECORDING o IDLE
    shell-recorder start screen 1 0  # Inicia grabando pantalla completa con audio del sistema
    shell-recorder start area 1 1    # Inicia grabando región con audio y micrófono

• Características:
    - Grabación de pantalla completa o selección de región/sección interactiva (slurp).
    - Selector de audio del sistema (aplicaciones/juegos/reproducción).
    - Selector de micrófono (voz y fuentes externas).
    - Mezcla en tiempo real con PipeWire para grabar audio interno + micrófono simultáneamente.
    - Indicador visual en la barra superior con temporizador activo ("REC 00:15") y punto rojo parpadeante.
    - Clic en el indicador de la barra detiene la grabación al instante.
    - Los vídeos se guardan automáticamente en: ~/Videos/screenrecoder/


17. HERRAMIENTA DE CUENTAGOTAS DE COLOR (COLOR EYEDROPPER)
-----------------------------------------------------
• Activar cuentagotas directamente:
    shell-colorpicker
    Atajo Hyprland: SUPER + SHIFT + P

• Características:
    - Lupa/Puntero interactivo directo para seleccionar cualquier píxel de la pantalla.
    - Copia automáticamente el valor HEX seleccionado al portapapeles.
    - Abre ventana modal con tarjeta de inspección de formatos:
        • HEX  (#RRGGBB)
        • RGB  (rgb(r, g, b))
        • HSL  (hsl(h, s%, l%))
        • HSV  (hsv(h, s%, v%))
    - Botones de copia individual con confirmación visual interactiva.
    - Botón "Seleccionar otro color" para tomar más muestras sin cerrar la ventana.
    - Compatible con hyprpicker nativo o motor integrado sin dependencias adicionales.

18. PANTALLA DE BLOQUEO MODERNA NATIVA (LOCK SCREEN)
-----------------------------------------------------
• Bloquear pantalla de inmediato:
    shell-lock
    Atajo Hyprland: SUPER + L
    O desde el Menú de Energía: SUPER + Escape -> Bloquear

• Características integradas:
    - Protocolo nativo ext-session-lock-v1 directamente en Quickshell (sin crasheos).
    - Gran reloj digital estilizado con sombra moderna y fecha completa en español.
    - Widget de clima y temperatura local en vivo (integrado con el servicio de información).
    - Tarjeta de autenticación con efecto de vidrio esmerilado (glassmorphism) y avatar de usuario.
    - Autenticación segura PAM directa mediante stdin (sin exponer contraseña en lista de procesos).
    - Animación de sacudida (shake) y mensaje visual descriptivo en caso de error.
    - Visualizador de audio reactivo en tiempo real (Cava) cuando se está reproduciendo música o sonido.
    - Píldoras flotantes superiores con información de hardware (Hostname, CPU %, RAM GB), contador de notificaciones pendientes, volumen de audio y estado de batería.
    - Desbloqueo rápido pulsando Enter o haciendo clic en la flecha de envío.
